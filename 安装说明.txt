DSH 聊天窗口
=============

装完之后，点侧栏的 Chat，对话会在一个单独的窗口里打开，任务栏上是它自己的
图标，不是 DSH 的图标。跟你现在看到的那个一样。


包里有什么
----------

  chat-in-dsh\     聊天界面本身
  plugin\          把聊天拎成独立窗口的那个
  安装.bat         只需要跑一次，情况见下面

两个文件夹都是「插件」，要装进 DSH 里。

先解压到一个以后不会挪走的地方，比如桌面上新建一个文件夹。放好之后就别再动
它了 —— DSH 装本地插件是指向这个目录的，挪走或者删掉，插件就没了。


先看一眼：你的 DSH 里有没有 chat-in-dsh
---------------------------------------

打开 DSH → Plugins（插件），看列表里有没有一行叫 chat-in-dsh 的。

  没有 → 按「第一路」装，最省事。
  有   → 按「第二路」装。你那份可能是新版本，用你那份。


第一路：还没装过 chat-in-dsh
----------------------------

1. Plugins →「添加插件」→ 选包里的 chat-in-dsh 这个文件夹。
2. 再「添加插件」一次 → 选包里的 plugin 这个文件夹。
3. 重启 DSH。

完了。点侧栏的 Chat 就有窗口。

这一步不用跑 安装.bat —— 包里那份 chat-in-dsh 已经处理好了。


第二路：已经装了 chat-in-dsh
----------------------------

1. Plugins →「添加插件」→ 只选包里的 plugin 这个文件夹。
2. 双击包里的 安装.bat。
3. 重启 DSH。

第 2 步是给已经装好的那份 chat-in-dsh 补一行代码。因为点 Chat 的时候，需要有人
告诉新插件「现在该开窗口了」，而这一行本来不在对方包里。

它会先备份原文件（同目录下的 client.js.bak-chat-window-kit），只改这一处，跑第二
遍什么都不会做，可以放心重复跑。

不要把包里的 chat-in-dsh 也装进去 —— 你已经有了，DSH 会拒绝，说已经装过。


以后可能会遇到的情况
--------------------

· chat-in-dsh 更新之后，点 Chat 又变成在面板里打开了，不弹窗口。
  正常的，更新会把那一行覆盖掉。重新双击一次 安装.bat 就好。

· 安装.bat 说「有几处没打上」。
  说明你那版 chat-in-dsh 和这个包对不上，代码形状变了。
  DSH 还是能正常用的，只是点 Chat 还是在面板里打开，不弹窗口。
  把黑窗口里的内容发回来，对着那一版改一下就好。

· 想去掉：Plugins 里把 chat-in-dsh 和 Chat window 都移除，然后把解压出来的
  文件夹删掉。


它是怎么工作的
--------------

chat-in-dsh 在 DSH 内部提供一个 /webchat/ 页面。plugin 那个插件监听「Chat 被点开」
这件事，然后把那个页面放进一个独立的窗口里，边缘不留任何 DSH 的界面元素。

开窗口有两种走法：能用 Electron 的窗口就用 Electron，图标在创建时就交过去；不行
就用 Edge 或 Chrome 的 app 模式开一个没有地址栏、没有标签栏的窗口。后一种窗口的
图标是浏览器按 32 像素的 favicon 放大画的，缩放屏幕上会糊，所以插件会在每次启动
时用脚本把真正的图标换上去（icon-apply.ps1，调的是 Windows 的 WM_SETICON）。

窗口属于正在运行的那个 DSH，关掉 DSH 窗口也跟着关。所以还在生成中的回答，窗口一
关就没了 —— 跟网页上刷新一样。

只支持 Windows。
